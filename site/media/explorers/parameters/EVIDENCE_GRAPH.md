# 관계의 종류를 보존하는 근거 그래프

이 그래프는 파라미터의 별칭, 코드의 선택된 계산 관계, 문헌 검토, 등록 출처, 원문 공동 추정 계보를 별도 관계로 기록합니다. 고정 스냅샷의 원본 선언 706행과 상세 검토 22패킷의 347개 고유 선언 행·189카드를 포함하며, 현재 생성물은 2,168노드·3,031연결입니다. 완전한 생물학적 의존성 그래프나 인과 그래프는 아닙니다.

앞선 기본 검토도 보존합니다. 49 SOURCED행, 전이 스키마 외 EXAMPLE 직접값 270행, 코드 카드 12개와 EXAMPLE 해석 관계 14개가 그 범위입니다. 기본 EXAMPLE 검토의 원문 대조 21카드·28행은 당시 범위이며, 이후 추가된 상세 검토의 전체 범위를 뜻하지 않습니다. 최신 직접 검토·별칭의 원래 입력 문맥은 [검토 범위](REVIEW_COVERAGE.md)에서 구분합니다.

`graph.html`은 전체 지도에서 시작합니다. 모든 2,168개 기록과 3,031개 연결을 입력·검토·계산/비교·출처의 역할별로 배치합니다. 휠 또는 버튼으로 확대하고 빈 곳을 끌어 이동하며, 이름이나 기록 선택 메뉴로 항목을 찾을 수 있습니다. 점을 누르면 직접 연결이 강조되고 아래에 설명이 나옵니다. 위치·거리·점 크기는 생물학적 유사도·인과·중요도를 뜻하지 않습니다.

`선택한 입력 주변`은 연결 거리와 관계 종류로 범위를 좁힙니다. 작은 범위의 열은 선택한 입력에서의 연결 거리이고, 70개를 넘으면 역할별 배치로 모든 기록을 표시합니다. 선의 방향은 기록의 역할이며 물리적 작용 방향이 아닙니다. 현재 범위의 전체 표·JSON과 지도 SVG 저장을 제공합니다. 관계 필터를 적용하면 표시 범위가 달라지며 화면에 그 수를 명시합니다.

| 관계 | 답할 수 있는 질문 | 그 관계만으로 답할 수 없는 질문 |
|---|---|---|
| `bound_to` | 이 설정에서 어떤 입력을 그대로 따르는가? | 두 생물학적 양이 독립적으로 함께 측정되었는가? |
| `selected_input_to_code_card` | 검토한 계산에 어떤 입력들이 함께 나오는가? | 모든 의존성을 찾았는가, 민감도가 얼마인가? |
| `review_describes_parameter` | 이 선언의 근거에 어떤 검토가 붙었는가? | PI가 태그·수치·전이를 승인했는가? |
| `review_cites_reference` | 검토에서 어떤 원문·후보를 확인했는가? | 그 논문이 현재 조건의 해당 숫자를 보증하는가? |
| `reference_has_registry_identity` | 어떤 등록 UID와 감사 판정이 대응하는가? | 숫자와 실험 문맥까지 지지되는가? |
| `parameter_in_shared_fit` | 원문에서 같은 적합으로 추정한 계보를 공유하는가? | 현재 MCF7 입력의 공동 fit인가, 공분산·상관계수가 얼마인가? |
| `declaration_mentions_reference` | 원본 source 문구에 어떤 인용 토큰이 있는가? | 그 인용이 실제 숫자의 근거인가? |
| `example_review_cites_primary_card` | EXAMPLE 검토에서 어떤 원문 대조를 했는가? | 예시값의 근거를 승인했는가? |
| `selected_input_to_example_relation` | 함께 해석해야 하는 정의·조건·분모는 무엇인가? | 수치적 제약이나 공동 분포를 확정했는가? |
| `example_reference_lists_registry_record` | 후보 DOI와 저장된 등록 기록은 어떻게 다른가? | 후보가 이미 감사된 동일 논문인가? |

ERM의 `k_off0`와 `x_beta`, α-actinin의 `crosslink.k_off0`와 `crosslink.x_beta`는 문헌 검토에 기록한 공동 적합 표식을 공유한다. 현재 MCF7 입력을 공동 적합했다는 뜻은 아니며, 공분산 수치가 없어 샘플링 분포를 생성하지 않는다. `crossbridge.x_adp`와 IIB 대응 값은 같은 논문과 환산 가정을 공유하지만, 이것을 공동 적합이나 관측 쌍으로 자동 승격하지 않는다.

같은 DOI를 가진 SE550/SE425 등도 UID별 기록과 감사 판정을 보존한다. 동일 DOI라는 이유로 CHECK를 OK로 덮어쓰지 않는다. 연결이 없다는 것은 이 감사에서 표현하지 않았다는 뜻이며 독립성의 증거가 아니다. 연결 수를 신뢰도·중요도·획득 우선순위 점수로 사용하지 않는다.

EXAMPLE 검토는 출판된 적합값과 현재 선언값의 차이를 다룰 수 있으므로 새 공동 적합 선을 만들지 않는다. 예를 들어 `filamin.x_beta`의 대조 카드는 현재값이 그 적합에서 나왔다는 뜻이 아니다. Fritzsche2013의 원문 후보 DOI와 SE110의 빈 저장 DOI도 따로 표시하며, SE110은 NO_DOI_FOUND로 남는다.

EXAMPLE 검토 버전 2는 논문 쪽 적합의 표식을 `source_comparison_fit_groups`에 보존하고, 현재 행의 `same_fit_groups`는 비워 둔다. 필라민 원문의 Hummer–Szabo 장벽 거리와 현재 Bell 길이를 같은 추정량으로 간주하지 않는다. 독립적인 4개 원문 대조는 `source_crosscheck`에 기록했다. 불확실성 41행의 검토는 탐색 화면과 query packet에 포함되지만, 현재 그래프의 새 노드·선으로 추가하지는 않았다.

프로그램에서는 `build_graph(atlas, kb, cards, literature_review, example_review=None)`로 기본 그래프를 만들고, `research_graph.attach_research(graph, atlas_dir)`로 상세 검토를 붙인 뒤 `neighborhood(graph, names, hops, kinds)`를 사용합니다. 명령행은 EXAMPLE 검토와 `research_catalog.json`이 있으면 각각 함께 읽으므로 위 명령으로 상세 그래프를 재현할 수 있습니다. `hops`는 0–3이며 입력한 관계 종류에 대해서만 양방향으로 문맥을 탐색한다. 반환된 선은 원래 방향을 유지한다. 양방향 탐색은 관계가 대칭적이라는 뜻이 아니다.

모든 파라미터 노드의 `supervision_mask`는 false다. `empirical_pairs=[]`, `empirical_covariance=null`, `training_performed=false`를 유지한다. 검색·표시와 공동 출처를 고려한 자료 정리에 사용할 수 있으며, 정답·인과 효과·식별성·prior를 만드는 권한은 없다.


## 상세 원문·수량 관계의 확장

22개 검토 패킷의 347개 고유 선언 행을 기본 그래프에 연결했습니다. 전이 스키마 외 직접 입력 339개와 별칭 8개의 직접 검토이며, 모든 별칭 141개는 바인딩을 통해 원래 입력의 문맥으로 이어집니다. 189개 카드는 원문 관찰, 적합, 모델 설정, 출처번호 확인과 공식 정의를 포함합니다. 수치 설정 8개는 정적 관계이며 원문 카드가 없습니다. 카드·노드·연결 수는 독립 논문·표본 수가 아닙니다.

| 추가 연결 | 뜻 |
|---|---|
| 상세 검토 → 입력 | 원 선언을 보존한 검토 대상 |
| 상세 검토 → 원문 카드 | 해당 수량에 필요한 원문 맥락 |
| 입력 → 수량 변환 | 조사한 코드·기하 계산의 관련 입력 |
| 입력 → 조건부 비교 | 원문 또는 코드 계산의 비교 범위; 현재 fit 소속 아님 |
| 조건부 비교 → 원문 카드 | 비교에 필요한 자료; 다른 실험/construct일 수도 있음 |
| 기록 → 서지 DOI 키 | 같은 논문의 식별자; 같은 표본이나 공동 fit을 뜻하지 않음 |

탐색 화면에서 ‘수량·원문 조건부 관계’를 선택할 수 있습니다. ‘공유 DOI 식별자’는 검토·카드를 통하는 접근 경로와 연결 거리 3을 사용합니다. 원문의 후보 DOI와 등록 기록의 저장 DOI는 각각의 역할·원문 문자열·UID를 유지합니다. 기존 공동 fit 선은 그대로이며 새 공분산이나 학습 라벨을 만들지 않았습니다.
