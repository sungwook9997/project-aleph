# 전체 검토 범위와 남은 질문

전체 706개 선언을 한 행씩 연결했습니다. 이 중 141개는 다른 입력을 참조하는 별칭입니다.
검토 범위는 작업 기록이며, 정확도·신뢰도·출처 채택 점수가 아닙니다.

| 범위 | 선언 행 수 |
|---|---:|
| 추가 상세 패킷에서 직접 검토 | 347 |
| 직접 검토 중 원문·문헌 맥락 포함 | 337 |
| 직접 검토 중 코드 수량 정의 포함 | 25 |
| 원래 입력의 상세 맥락을 따라갈 수 있는 별칭 | 141 |
| 이번 추가 상세 패킷에 직접·별칭 맥락이 없는 행 | 226 |

행 수는 서로 겹칩니다. 문헌 맥락에는 직접 측정뿐 아니라 저자 적합·모형·다른 종에서 옮겨온 값·단위 정의도 포함됩니다.
추가 상세 패킷이 없다고 원문이 없다는 뜻은 아닙니다. 앞선 SOURCED·EXAMPLE·불확실성 검토는 별도 열에 남았습니다.

[필터 가능한 CSV](review_coverage.csv), [정밀 JSON](review_coverage.json), [화면에서 탐색](index.html).

CSV는 다음 순서로 읽으면 됩니다.

1. `name`, `root`, `is_bound_alias`: 독립 입력인지 기존 입력의 별칭인지 확인합니다.
2. `broad_review_roles`, `direct_detailed_packets`: 예시·직접 측정·유도·모형 등 검토 역할과 상세 문서를 찾습니다.
3. `root_context_packets`: 별칭에서 원래 입력의 근거를 따라갑니다. 새 측정이나 새 표본 수로 세지 않습니다.
4. `prior_status`: 기존 범위와 폭의 상태입니다. 범위가 적혀 있다는 사실은 표본 분포나 신뢰구간을 입증하지 않습니다.
5. `kb_parameter_record_ids`, `kb_difference_fields`: 고정 KB 미러와 현재 선언의 차이를 확인합니다. 이 표는 Notion을 고치지 않습니다.
6. `open_metadata_questions`: 다음 자료 검토에 필요한 질문입니다. 자동 채택·순위·학습 정답을 만들지 않습니다.

원문 해석은 각 패킷의 관측 단위·조건·가정·한계를 함께 읽어야 합니다. 모든 `supervision_mask`는 false이며 현재 파라미터·prior·태그는 유지했습니다.
