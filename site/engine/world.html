Physics engine / Foundations

World and nodes

The world is one set of nodes. Every node has a mass and a radius, and every node can move: there is no fixed node and no separate solver per component. Mechanics and hydrodynamics act as one operator over all of them.

Laws

This part has no law card of its own; it is the machinery the laws run on.

Where it lives in the code

  • aleph/physics/world.py
  • aleph/physics/objects.py
