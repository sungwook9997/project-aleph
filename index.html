01

실제 상태를 관찰합니다

엔진이 계산한 위치·힘·유동장을 이미지와 영상으로 확인합니다. 기록과 연결되지 않은 연출용 움직임은 물리 근거로 사용하지 않습니다.

OBSERVATION
02

독립적인 비교가 필요합니다

물리적 적합성을 판단하려면 단위, 보존량, 경계 조건과 측정 방법을 명시하고 독립적인 해석해나 실험 기준과 비교해야 합니다. 현재 시연에는 이 비교가 아직 없습니다. 엔진 자신의 출력을 정답으로 삼지 않습니다.

INDEPENDENT REFERENCE
03

전체 세포에서 다시 묻습니다

부분 시연은 해당 조건의 진단입니다. 정상 세포 작동에 대한 결론은 생리학적 조건의 전체 개체수와 구획을 포함한 실행에서 별도로 확인해야 합니다.
