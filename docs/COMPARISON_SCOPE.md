# What must exist before a numerical agreement claim

The current release adds source-level mappings, actual external observations and
postprocessing of existing captures. It does not complete physical validation.

1. Membrane/cortex: reproduce the source study's tether probe geometry, attachment,
   pulling protocol and extraction window. Compare the same force observable,
   preserving cell and experiment identity. Existing node maximum force is not
   that observable.
2. Cortex/motors/fluid: reproduce AFM confinement, cell state, height and oscillatory
   protocol; retain force, height and shape. Apply the same author observation
   model before comparing published medians. The summaries cannot supply raw
   force traces, distributions or invented uncertainty.
3. Filament/motor, nuclear structures, growth and contact: acquire direct,
   condition-matched independent measurements before assigning an agreement score.
   Whole-cell AFM curves cannot uniquely validate each constituent.

Current captures are tied to bb597f087. Instrument builders subsequently added in
other engine work are outside that capture snapshot and have not been validated
or exercised by this website task. Do not quietly attribute those capabilities
to these records. New runs require exact source receipts and the project's GPU,
physical population, parameter and model authorization rules.

No model, physiological parameter, numerical threshold or engine implementation
was changed to make this website look more complete.
